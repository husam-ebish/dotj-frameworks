# UnicodeEncoding specialized decoder heap spans

Batch 2243 adds specialized decoder heap-span count/write overrides. The count forwards the actual flush value to the owned array core. The writer snapshots the source and current destination view, calls the flush-aware owned core and copies the complete view back in a finally block. Characters written before an exception therefore remain observable while protected outer elements remain untouched. Later decoder carry follows the preceding array core's native state rules.

The baseline packaged JAR reproduces event 183: a one-byte view with flush true should count one fallback character, but the inherited generic adapter reports zero because it calls the no-flush array overload. The specialized adapter passes all 463,680 comparison groups against 66,240 native cases and ten byte-order/fallback profiles. Six seed states combine pending odd bytes and high-surrogate words with full/clipped/empty input views, both flush modes, six capacities, nonzero offsets and three protected suffix characters. Each case records a seed array write, span count, span write and final empty array flush: 264,960 native calls. Exact exception payloads and complete buffers are compared, including partial replacement output and strict previous-call byte indexes.
