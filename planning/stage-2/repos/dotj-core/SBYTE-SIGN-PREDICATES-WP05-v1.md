# SByte sign predicates

Batch 2156 adds IsPositive and IsNegative. All 256 native signed-byte values are checked through both predicates, totaling 512 exhaustive consumer groups. Zero is positive under this native predicate and is not negative.

The selected signature inventory now records 134 direct projections and forty native parsing overloads represented through typed bridges. Other numeric APIs, native generic interfaces, CLR value ABI, implementation-task acceptance and release qualification remain open. The product remains JDK-only and validation artifacts remain on D:.
