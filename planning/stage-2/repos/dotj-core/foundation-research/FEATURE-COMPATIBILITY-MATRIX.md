## Claim restrictions

No exact API/source/binary compatibility is asserted. Public reference declarations do not prove runtime behavior. Test method selection does not mean tests were executed. The current source pin's prerelease tooling and newer features must be reconciled with the chosen release family. Keyed DI, open generics, CLR ambient contexts, native wait handles, async startup validation and numeric/time edge cases remain explicit contract work.

## Entire retained scope

The 218-directory inventory includes many untouched groups: collections/LINQ/expression trees, XML/serialization, crypto, networking, threading/dataflow/channels, reflection, interop, OS integration and runtime support. None is removed. A complete Stage-2 plan must assign each group and API a Java disposition and validation path before declaring core detailed analysis complete.
