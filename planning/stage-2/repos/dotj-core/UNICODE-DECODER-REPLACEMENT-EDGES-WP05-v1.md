# UTF16 decoder standard replacement NUL and surrogate edges

Batch 2250 matches returned stateless and stateful UnicodeEncoding decoder array behavior for eighteen endian/replacement configurations. The replacement strings include empty values, standalone NUL, prefix/suffix/embedded NUL and valid surrogate pairs. The dedicated native decoder corpus contains 25,920 cases combining eight input shapes, four stateful seed states, flush modes, count-before-write controls, capacities, offsets, empty flushes and later buffer cursor calls. Every case returned under the pinned runtime; this corpus is separate from the combined encoder/decoder watchdog matrix.

The baseline JAR fails event 11512: an odd byte with a NUL replacement and zero destination capacity should return zero written characters, but the stateless path attempts to write NUL and throws overflow. The correction routes stateless writes through the actual standard fallback buffer, whose NUL return terminates that drain. Counts preserve the native replacement-length fast path. For example, a one-character NUL replacement can count as one character and write zero; A followed by NUL can count as two and write one. The distinction is recorded behavior, not inferred equality between count and output.

The packaged consumer passes 427,680 groups. It compares exact exceptions, whole buffers, returned counts, remaining fallback data and cursor observations across stateless/stateful cases. The owned stateful decoder already uses its actual fallback buffer; the changed condition is in the stateless decoding core. Existing non-NUL behavior is retained by the relevant array/span, fallback and encoder/decoder consumers. Native producer/fixture, consumer source and candidate JAR hashes bind the selected proof.
