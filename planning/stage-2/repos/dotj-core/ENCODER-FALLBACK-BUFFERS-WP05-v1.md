# Selected encoder fallback buffers

Batch 2172 adds EncoderFallbackBuffer, replacement/exception factories and selected cursor state. Replacement buffers return UTF-16 units, expose Remaining, support MovePrevious and Reset, preserve recursion failure state and validate surrogate pairs before recursion checks. Pair fallback emits two replacement strings. Empty strings and NUL replacements preserve the distinction between reading a real unit and reading an exhausted sentinel; rewinding the sentinel may leave Remaining at zero. Repeated exhausted reads can disable rewind.

Exception buffers preserve single-character and surrogate-pair payloads, including arbitrary Int32 indexes, null parameter names, HResults, CharUnknown/High/Low and IsUnknownSurrogate. Public exception constructors retain their prior zero/default payloads. The base Reset loop was checked against the SHA-256-verified pinned runtime source archive; selected replacement buffers override it to clear state.

Eight pinned profiles with 51 transitions each produce 1,232 packaged groups, including fresh factory instances and before/result/after state. Native private runtime buffer names are recorded but not qualified by the candidate's private implementation classes. Error message parity, custom encoder integration, decoder buffers, full reflection/source ABI and WP-05-T2 acceptance remain open. Source/class ownership explicitly includes the new base source and both private buffer classes. No accepted task or framework is credited.
