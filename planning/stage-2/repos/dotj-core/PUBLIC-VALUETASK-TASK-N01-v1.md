# Selected nongeneric ValueTask Task lifetime contract

This stable contract defines `ValueTask(Task)`, `AsTask()` and `Preserve()` and their private Task prerequisite. Current qualification and integration status belongs to [Batch-2515](../../implementation/batches/Batch-2515.md) and [implementation state](../../IMPLEMENTATION-STATE.md). Native source semantics, fixture membership and exclusions are pinned in [the frozen native contract](../../../../tools/oracle/dotj-core/public-valuetask-task-v1/frozen-native-contract-v1.json). The evidence record is [public-valuetask-task-v1.json](evidence/public-valuetask-task-v1.json).

Task-backed values delegate predicates, normal/configured results and continuation registration to the existing Task profile. A null Task constructor argument throws ArgumentNullException(task). AsTask returns the original Task. Completed values use CompletedTask. Equality compares backing identity and short token; hashing uses virtual backing hashing. Java object identity does not establish CLR struct-copy identity.

Source conversion reads status once outside the result catch. Nonpending conversion consumes GetResult once, returning CompletedTask on a normal return regardless of the observed status. Canceled status plus OperationCanceledException stores the original exception and original token, including unsignaled tokens. Repeated awaits rethrow that original object. Canceled status plus an ordinary exception produces token-only cancellation with a precanceled token. An OCE under any noncanceled status remains a fault. Task.Exception remains null for canceled outcomes.

A private composition adapter owns a final Task and initializes its source/token before registration. It registers None flags, supports inline completion, validates state, clears its retained source before reading callback status, and consumes the result once. Status and registration failures propagate at their own boundary; callback status failure leaves the Task pending and detached. Sequential duplicate, null and wrong callback states throw ArgumentOutOfRangeException(state). Completion dispatch stays outside the source-result catch.

Preserve converts a source once to a reusable Task-backed value. Original consumed source-backed values have no general reuse guarantee. Direct source flags remain 3/1/3/2/1/0. Task context handling remains the existing default-context/shallow-stack profile. Arbitrary concurrent duplicate callbacks, stable canceled-cache identity under races, full execution/context flow, generics, async builders, struct semantics and broad reflection parity remain outside this contract.

Private Task completion writes original cancellation cause and token before volatile terminal status publication, preserving waiters, continuations, public TCS behavior and Java interruption restoration. Foreign Java result Throwables are wrapped in System.Exception with their cause preserved and classified by prior source status; foreign status/registration failures propagate unchanged. These are Java-only adaptations.

Verification uses the frozen 115-row/1884-field native capture, eight Java-only groups, and same-JAR Task61/697+49, WorkTask66/612+8, delegate34/cancellation48/ValueTask135. The pure classfile surface check allows exactly the three additions and no public producer APIs. Every fixture is isolated from product sources. All three E01 decisions remain open; selected observations carry zero task/framework acceptance credit.
