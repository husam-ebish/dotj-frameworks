# WP-01-T1 nullability, type identity and exception contract v1

Profile: pinned .NET 10.0.12 CoreLib and a bounded Java 21 foundation candidate. Status: **provisional; DJ-001-WP-01-T1 remains in progress**. This contract describes selected observations and explicit mapping decisions. It does not qualify the full `System.Type` or `System.Exception` public API.

| Topic | Pinned observation | Java candidate decision | Qualification boundary |
|---|---|---|---|
| Closed generic identity | Repeated `Dictionary<string,int>` and reconstructed `List<int>` have the same CLR type identity; selected different type arguments differ. | Keep generic definition, ordered arguments and loader identity in the internal type key. Current `TypeIdentity` checks concrete Java reflection types by structural equality and rejects wildcard/type-variable forms. | The internal key is not `System.Type`; its full public representation and CLR type-loading behavior are open. |
| Open generic parameters | The pinned `List<>` and `Dictionary<,>` definitions return one and two canonical generic parameter `Type` values with positions 0 and 0/1. | The selected Java `System.Type` candidate now returns definition-specific, stable parameter objects and defensive arrays; the external consumer checks the list case. | Generic parameter names, constraints, declaring methods, variance and the complete reflection surface remain open. |
| Selected type-name lookup | The pinned oracle resolves `System.String`, `System.Int32`, ``System.Collections.Generic.List`1`` and ``System.Collections.Generic.Dictionary`2`` to canonical types, and returns null for `System.Unknown`. The overloads resolve `system.string` with `ignoreCase=true`; an unknown bare name with `throwOnError=true` throws `TypeLoadException`. Selected `System.Private.CoreLib` and `mscorlib` qualifiers resolve `System.String`; an unknown assembly with `throwOnError=true` throws `System.IO.FileNotFoundException`. | Public `System.Type.GetType(String)`, `GetType(String,boolean)` and `GetType(String,boolean,boolean)` candidates recognize four selected names and the two observed simple assembly aliases, preserving canonical identity. The selected unknown-assembly error uses candidate `System.IO.FileNotFoundException` and `IOException` inheritance. | Java `String` remains a backend type; full assembly grammar, resolver overloads, I/O exception properties and exact error messages remain open. |
| Selected name boundaries | The pinned oracle accepts one leading space before `System.String` but rejects a trailing space, including before the assembly comma. An empty assembly returns null or raises `ArgumentException` with `ParamName=typeName@13` when throwing. | The candidate strips leading whitespace only, preserves trailing name whitespace, and maps the selected empty-assembly error. | Other malformed names, whitespace classes, parser offsets and localization remain open. |
| Selected array and generic names | The pinned oracle resolves `System.String[]`, `System.Int32[]`, and both simple and CoreLib-qualified forms of ``List`1[System.String]`` to canonical CLR types. | The candidate resolves these selected forms to canonical Java backend `Type` values and ignores commas nested inside generic brackets when finding an outer assembly qualifier. | Other ranks, element types, generic forms, full grammar and CLR/JVM array behavior remain open. |
| Selected two-argument generic names | The pinned oracle resolves simple and CoreLib-qualified `Dictionary<string,int>` names to the same type, while swapping arguments changes identity. | The candidate recognizes these selected forms and returns the same canonical constructed value as `MakeGenericType` in argument order. | Broader generic grammar, nested types, escaping and reflection parity remain open. |
| Array rank distinctions | The pinned oracle resolves jagged `System.String[][]`, rectangular `System.String[,]`, rank-three `System.String[,,]`, and a one-dimensional array of `List<string>` as distinct CLR names. | The candidate resolves jagged `System.String[][]` and uses a bounded array-shape identity for the selected rectangular and generic-element array names. | Complete array reflection, constructor behavior and shape grammar remain open. |
| Selected array reflection | The pinned oracle reports `IsArray`, `GetElementType` and `GetArrayRank` for the six selected names. Jagged arrays have rank one and an array element; non-array `GetArrayRank` raises `ArgumentException`. | The candidate exposes these three selected members for JVM and bounded CLR-shape arrays, returning canonical element values and the selected ranks. | Other `Type` array properties/methods, exact exception messages and all array forms remain open. |
| Selected array construction | The pinned oracle distinguishes vector `string[]` from rank-one non-vector `string[*]`; rank two is `string[,]`, `string[]` can become jagged, `List<string>` can become a vector, and rank zero raises `IndexOutOfRangeException`. | Candidate `MakeArrayType()` and `MakeArrayType(int)` preserve these selected identities and error type. | General array rank limits, all element kinds, complete reflection semantics and exact messages remain open. |
| Selected by-reference type | The pinned oracle resolves `System.String&` and `System.String[]&`; repeated `MakeByRefType` returns the same CLR type, `IsByRef` is true, `GetElementType` returns the underlying type, and a second by-reference layer raises `TypeLoadException`. | The candidate interns by-reference values and exposes the selected members and error type. | By-reference use in signatures, every element kind, complete `Type` behavior and exact messages remain open. |
| Selected pointer type | The pinned oracle resolves `System.String*` and `System.Int32*`; repeated `MakePointerType` preserves identity, another pointer layer is permitted, and pointer creation from a by-reference type raises `TypeLoadException`. | The candidate interns pointer values, exposes `IsPointer` and canonical element lookup, and maps the selected error type. | Unsafe execution, calling conventions, all pointer element kinds and complete `Type` behavior remain open. |
| Selected type names | The pinned oracle records `Name`, `FullName` and `Namespace` for string, int, open/closed List, vector/rectangular arrays, by-reference and pointer strings, and an open List parameter. The parameter has `FullName=null` and namespace `System.Collections.Generic`. | The candidate exposes these three projections for selected values, including pinned CoreLib assembly-qualified generic arguments. | General name grammar, assembly identity/version evolution and nonselected Java-backed types remain open. |
| MemberInfo base and Name | Pinned reflection shows `System.Type` inherits `System.Reflection.MemberInfo`; the base has abstract `Name` and no public constructor. | The candidate Type now extends a public abstract MemberInfo base; concrete backend Type values implement the inherited abstract `get_Name` member, checked through a MemberInfo reference. | The remaining MemberInfo methods, properties and reflection hierarchy are open. |
| Member kind | Pinned `MemberTypes` values include `TypeInfo=32` and `All=191`; `MemberInfo.MemberType` is abstract, and selected Type values report `TypeInfo`. | Candidate MemberInfo exposes abstract `get_MemberType`; selected Type values return a provisional Java `MemberTypes.TypeInfo` with the pinned numeric value. | Java enum inheritance differs from CLR Enum; other MemberInfo members and reflection behavior remain open. |
| Member owner types | Pinned `MemberInfo.DeclaringType` and `ReflectedType` are abstract; Type overrides both. Selected top-level, constructed, array, by-reference and pointer types return null, while an open List parameter returns its List definition for both. | Candidate MemberInfo declares both abstract getters and Type provides the selected owner values, checked through a MemberInfo reference. | Nested types, reflected member lookup and the full reflection hierarchy remain open. |
| Selected base type | Pinned `BaseType` is null for `object`, by-reference and pointer types; string, List and an open List parameter derive from object; int derives from ValueType; arrays derive from Array. | Candidate `get_BaseType` projects these selected canonical values using Java backend classes for Object, ValueType and Array. | These Java classes do not implement the full CLR class hierarchy or behavior; nonselected inheritance and qualification remain open. |
| Selected kind flags | The pinned oracle reports `IsValueType=true` for int and MemberTypes among 14 selected values; `IsClass=true` for selected reference, generic parameter, pointer and by-reference values. | Candidate getters reproduce those selected flags. | Generic constraints and the full CLR classification rules remain open. |
| Interface and enum flags | Pinned `IDisposable` reports interface true and class/value-type/enum false; `MemberTypes` reports enum and value-type true and class/interface false. | Candidate `GetType` exposes these two selected identities, and the four kind getters reproduce the pinned flags. | Full interface inheritance, enum behavior and nonselected classifications remain open. |
| Selected enum base | Pinned MemberTypes derives from Enum, Enum derives from ValueType, and MemberTypes has Int32 underlying type; asking a non-enum raises ArgumentException. | Candidate Type projects these selected canonical base and underlying values and the selected error type. | Java Enum inheritance and full CLR enum behavior remain different and unqualified. |
| Selected assignability | Pinned 16-case matrix covers object boxing/interface/array sources, by-reference/pointer exclusions, ValueType and Enum chains, array base, open versus constructed List, identity and null. | Candidate `IsAssignableFrom(Type)` checks canonical identity and selected base chains, with object accepting selected interface and value types but excluding pointer/by-reference values. | Interface implementation graphs, variance, generic constraints and complete CLR assignability remain open. |
| Selected subclass relation | Pinned ten-case matrix covers string/int/enum/array chains, interface versus Object, open versus constructed List, self and null; a null target raises ArgumentNullException with `ParamName=type`. | Candidate `IsSubclassOf(Type)` follows selected base chains and maps the observed interface/Object and null cases. | Full CLR subclass rules, variance and interface inheritance remain open. |
| Selected runtime instance relation | Pinned 14-case matrix covers object, string, boxed int, ValueType, Enum, Array, vector string array, IDisposable and open List, including null. | Candidate `IsInstanceOfType(Object)` maps those selected Java runtime objects to the pinned results; open generic List remains false. | JVM erasure prevents broad CLR generic-instance parity; array-shape instances and complete interface graphs remain open. |
| Selected interface query | Pinned object and IDisposable both return an empty `GetInterfaces` array; their selected `GetInterface` misses return null, while a null name throws ArgumentNullException with `ParamName=fullname`. | Candidate exposes both overloads and those empty/miss behaviors, and rejects unmapped type queries explicitly. | Complete positive interface graphs, inherited interfaces and broad lookup are open. |
| Selected positive interface lookup | Pinned String resolves `System.IComparable` by full or short exact name; lowercase full name returns null even with `ignoreCase=true` in the selected observation. IComparable is assignable from String and recognizes a String instance. | Candidate adds public non-generic IComparable, the selected String lookup, and matching bounded assignability/instance results. | String's full interface list, all other positive lookups and Java-versus-CLR comparison behavior remain open. |
| Null input | Pinned `System.Type.MakeGenericType(null Type[])` and `Type.GetType(null)` throw `System.ArgumentNullException` with `ParamName=typeArguments` and `typeName`, respectively. | The selected Java `System.Type` candidate throws a same-named `System.ArgumentNullException` and exposes the selected parameter name; the external consumer checks it. The separate internal `TypeIdentity.of(null)` still uses `NullPointerException("type")`. | The Java exception hierarchy is a candidate backed by `RuntimeException`; full constructor/message, `System.Exception`, and other null-input parity remain open. |
| Disposal exception | In the selected `using` case, a failure from `IDisposable.Dispose` takes precedence over the body failure; the caught exception is the same instance thrown by `Dispose`, and its `InnerException` retains the same cause object. | The product `System.IDisposable.Dispose()` interface dispatches to its implementation. Selected `System.Exception`/`ArgumentException` constructors and `get_InnerException` retain the same cause object; the external consumer checks the pinned parameter/message form. | Java `RuntimeException` remains the backend base; complete `System.Exception` properties, stack behavior, localization and Java cause conversion are open. |
