This maps bounded state facets of 54 selected reference cases and explicitly leaves `defaultValueTask`, `defaultGenericValueTask`, and `whenAllResultOrder` outside the prototype. The five Java async fixtures include two 200-round races and five 100-round timed-wait race modes. The timed-wait fixture also checks zero/finite/infinite ordering, source and sibling independence, external future cancellation, listener and timer cleanup, repeated waits, and a daemon timer thread. These checks do not prove Java/.NET behavioral equivalence or exhaust thread interleavings. The public `Task`/`Task<TResult>`, `TaskCompletionSource`/`TaskCompletionSource<TResult>`, and `ValueTask`/`ValueTask<TResult>` naming collisions remain unresolved.
