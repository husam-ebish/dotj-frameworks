This maps the state facets of 27 selected reference cases and explicitly leaves 30 cases outside the prototype. A second Java fixture releases three workers together to race success, fault, and cancellation for 200 rounds. It checks exactly one winner, stable terminal state, retained result or fault identity, and agreement of the completion-backed view. A third fixture checks wait cancellation independence, source-first result, fault and cancellation propagation, and a pre-signaled wait. It also runs 100 completed waits on one long-lived signal and verifies that each wait removes its callback. A fourth fixture races source completion with wait cancellation for 200 rounds, accepts either wait outcome, requires the source to succeed, and checks callback cleanup. The fixtures do not prove Java/.NET behavioral equivalence or exhaust all thread interleavings. The public `Task`/`Task<TResult>`, `TaskCompletionSource`/`TaskCompletionSource<TResult>`, and `ValueTask`/`ValueTask<TResult>` naming collisions remain unresolved.
