# Selected encoder and decoder fallback objects

Batch 2171 adds EncoderFallback/DecoderFallback, their replacement and exception implementations, and selected UTF8Encoding fallback getters. Native replacement defaults use question mark; UTF-8 replacement profiles use U+FFFD. Replacement constructors accept valid UTF-16 including empty strings, NUL and surrogate pairs, and reject null or unpaired-surrogate replacement strings with native parameter/HResult identity. MaxCharCount counts UTF-16 units. Selected Equals behavior preserves value, direction/type and null distinctions.

Pinned CoreLib supplies 34 constructor cases, four static singleton profiles and four UTF-8 profiles. Separately constructed replacement encodings own distinct fallback objects; strict exception fallbacks share singleton objects. Encoding clones preserve both fallback references. The packaged consumer passes 132 selected groups.

Buffer creation and mutable fallback customization remain unimplemented in this batch. Native buffer runtime names and equal-object hash invariants are recorded without qualification. GetHashCode algorithm equivalence, full logical type/member metadata, inherited Object/Java equality/hash interoperability, internal default runtime identity, source/CLR ABI and WP-05-T2 acceptance remain open. The selected Equals facade bridge does not qualify the entire Object contract. All six sources and both private singleton-holder classes require explicit source/class ownership entries and JDK-only distribution audits. No acceptance credit is assigned.
