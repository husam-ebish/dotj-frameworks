# Stateful UTF-8 contract baseline

Batch 2186 pins the native System.Text.Encoder and Decoder declarations before implementing selected stateful candidate behavior. Encoder has thirteen declared public methods and Decoder fifteen, including fallback properties, Reset, count/write array and pointer/span overloads, and Convert forms. Both bases are abstract with protected constructors. Complete declarations do not establish a Java representation for span/pointer or out parameters.

Eight native profiles cover both UTF-8 constructor flags and directions. Each GetEncoder/GetDecoder call returns a fresh state object which initially shares its fallback object with the encoding. Ten sequences per profile record 236 transitions: split surrogate/scalar input, incomplete byte prefixes, count versus writing calls, flush, Reset, fallback replacement, failures and recovery. Count calls observe pending state without consuming it in the selected sequences; writing calls retain or consume pending units. The capture records native exception payloads and complete destination state for later differential implementation tests.

The gate audits capture integrity, twenty-eight declarations, eighty sequences and the selected baseline invariants. It records candidate Encoder/Decoder class presence separately and explicitly credits no stateful candidate behavior. This is prerequisite contract evidence, not an implementation-task acceptance or qualified framework. Other stateful inputs, small buffers, custom fallbacks, Convert, span/pointer APIs, complete metadata/source ABI and WP-05-T2 acceptance remain open.
