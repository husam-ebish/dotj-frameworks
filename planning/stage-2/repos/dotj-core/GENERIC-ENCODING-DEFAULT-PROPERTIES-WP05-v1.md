# Generic Encoding constructors, fallback properties and empty preambles

Batch 2222 adds the three selected protected Encoding constructors: default, code page, and code page with encoder/decoder fallback arguments. Negative code pages throw ArgumentOutOfRangeException with codePage, the actual integer value and the observed message. Non-negative values, including values above 65535 and Int32.MaxValue, are retained. Null constructor fallback arguments independently select the native replacement singletons.

Generic fallback getters/setters now provide the native defaults. Setters reject a read-only instance before checking null and accept provider changes on a mutable clone. Memberwise cloning preserves code-page values and provider references while allowing later field changes without mutating the original. UTF8Encoding uses base storage, initializes the base code page to 65001 and preserves its existing selected provider choices. Generic GetPreamble returns a shared empty array; UTF8 without an identifier uses that same array while identifier output remains a fresh array.
